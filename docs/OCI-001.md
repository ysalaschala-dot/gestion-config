# OCI-001 - Ampliación del registro y trazabilidad de recepción

**Motivo:** fortalecer la relación entre recepción, lote y trazabilidad.

**Elementos afectados:** pesajes de entrada, seguimiento de lotes y trazabilidad.

**Criterios de aceptación**
1. La recepción queda asociada al lote.
2. El lote puede consultarse por identificador.
3. No se afectan las demás funciones.

**Flujo:** Issue/OCI -> análisis -> feature/cambio-propuesto -> pruebas -> Pull Request -> develop -> versión 1.1.0.
